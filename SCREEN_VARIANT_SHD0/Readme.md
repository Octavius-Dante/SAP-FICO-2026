# Screen Variant SHD0

The SAP SHD0 transaction code is used to create and maintain transaction variants and screen variants without writing any ABAP code

</br>

#### Key Capabilities

**- Hide Fields:** Make unnecessary or sensitive fields invisible to users.

**- Pre-fill Default Values:** Automatically populate specific fields with standard data.

**- Make Fields Mandatory:** Force users to enter data into a field before saving.

**- Read-Only / Display-Only:** Restrict fields so users can view them but cannot edit them.

**- Hide Menus or Subscreens:** Simplify user interfaces by removing unwanted tabs, buttons, or menu options

**- Disable Menu Functions :** Hide Specific buttons, menu items, or entire tabs.

</br>

#### How It Works (Basic Steps)

1. Enter T-Code SHD0 and input the target standard transaction code (e.g., VA01, MB21, FB50).

2. Create a Variant Group under the Standard Variants tab.

3. Record the Transaction: SAP launches the target transaction in recording mode so you can 
step through and adjust screen attributes.

4. Save and Assign: Save the screen/transaction variants, and optionally link them to a custom transaction code using SE93 or assign them to specific user groups.
